# Bloom & Petal — Flower Shop Website

A single-page flower shop website built with plain HTML, CSS, and JavaScript.

## Files

- `index.html` — the full website (hero section, product grid, about, contact form)

## How to view

Open `index.html` directly in any web browser — no build step or server required.

## Sections

- **Home** — hero banner with intro and call-to-action
- **Shop** — grid of 6 bouquets with prices and "Add to Cart" buttons
- **About** — shop story/description
- **Contact** — a simple contact form

## Deployment

Live at https://bloom-and-petal-lyart.vercel.app, deployed via Vercel.
